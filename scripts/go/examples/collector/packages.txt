#   * 每行一个 module，可写 module@version 精确指定版本；省略 @version 视为 @latest
#   * 以 # 开头的行与空行会被忽略
#   * 脚本会 go get 每个条目并下载其【全量传递依赖】，生成 collector/go.mod|go.sum
#   * 离线按目标工程构建时，务必用目标工程自身 go.mod/go.sum 的精确版本；
#     本清单用于“尽量多覆盖指定包”，@latest 只锁构建时最新版，可能不匹配历史版本
#   * 带 @version 的条目为【内网 Go 1.25.3 兼容上限版本】：这些模块的最新版已要求
#     Go >= 1.26，内网工具链无法使用；此处锁定各自「要求 Go <= 1.25.3 的最新版」。
#     升级内网工具链到 >= 1.26 后可去掉对应 @version 恢复 @latest。
