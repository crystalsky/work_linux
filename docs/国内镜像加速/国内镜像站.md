vaultwarden/server:latest 是 Docker 镜像，直接用 Docker 拉就行。

一、官方源（能连 Docker Hub 时）

docker pull vaultwarden/server:latest


二、国内拉不动时用镜像加速

方式 1：直接从前缀镜像站拉
docker pull docker.m.daocloud.io/vaultwarden/server:latest
# 拉完改回官方名字
docker tag docker.m.daocloud.io/vaultwarden/server:latest vaultwarden/server:latest


其他常见前缀：
docker pull swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/vaultwarden/server:latest
docker tag  swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/vaultwarden/server:latest vaultwarden/server:latest


方式 2：配置 Docker 加速器（推荐）
编辑 /etc/docker/daemon.json：
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://hub-mirror.c.163.com"
  ]
}

然后：
sudo systemctl daemon-reload
sudo systemctl restart docker
docker pull vaultwarden/server:latest

阿里云也有专属加速地址：容器镜像服务 → 镜像工具 → 镜像加速器。

三、拉完跑起来（最小可用）

docker run -d \
  --name vaultwarden \
  --restart unless-stopped \
  -p 8080:80 \
  -v /opt/vaultwarden/data:/data \
  -e SIGNUPS_ALLOWED=true \
  -e TZ=Asia/Shanghai \
  vaultwarden/server:latest

浏览器开 http://服务器IP:8080 就能看到 Web Vault。

四、小建议

生产环境别用 latest，用固定版本更稳，比如：
docker pull vaultwarden/server:1.37.3

可以通过 GitHub Releases 查当前稳定版。
