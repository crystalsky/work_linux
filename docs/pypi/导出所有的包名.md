导出内网 `pypiserver` 中所有包名有以下三种常用方式，按操作权限和网络环境选择最适合的一种：

---

### 方法一：通过 HTTP 接口导出（无需服务器权限，推荐）

`pypiserver` 遵循 PEP 503 规范，其 `/simple/` 页面列出了所有已索引的包。如果服务端未关闭 simple 页面展示，直接通过脚本或命令行拉取解析即可：

#### 方案 A：单行 Shell 命令（Linux / macOS / Git Bash）

```bash
curl -s http://<pypiserver-ip>:<port>/simple/ | grep -oP '(?<=<a href=")[^"/]+' | sort -u > packages.txt

```

*如服务设置了 HTTP 基本认证（Basic Auth），在 `curl` 中加入 `-u username:password` 即可。*

#### 方案 B：Python 脚本（全平台通用）

```python
import re
import urllib.request

# 替换为你的 pypiserver 地址
SIMPLE_URL = "http://<pypiserver-ip>:<port>/simple/"

req = urllib.request.Request(
    SIMPLE_URL,
    headers={"User-Agent": "Mozilla/5.0"}
)
# 如果有账号密码认证：
# import base64
# credentials = base64.b64encode(b"user:pass").decode("ascii")
# req.add_header("Authorization", f"Basic {credentials}")

with urllib.request.urlopen(req) as resp:
    html = resp.read().decode("utf-8")

# 提取 <a href="..."> 中的包名
packages = sorted(set(re.findall(r'<a href="([^"/]+)/?"', html)))

with open("packages.txt", "w", encoding="utf-8") as f:
    for pkg in packages:
        f.write(f"{pkg}\n")

print(f"导出成功，共 {len(packages)} 个包，已保存到 packages.txt")

```

### 方法二：直接在服务器存放目录解析文件名（拥有服务器访问权）

如果能登录托管 `pypiserver` 的主机或容器，直接扫描包存储目录速度最快、最完整。

#### 1. 查找包存储根目录

检查启动命令或 Systemd/Docker 配置中的目录参数（通常是 `pypiserver run /path/to/packages` 或 Docker 挂载的 `/data/packages`）。

#### 2. 提取唯一的包名

Python 包的标准命名规则中，版本号前通常紧跟 `-`（例如 `requests-2.31.0-py3-none-any.whl`、`flask-2.2.0.tar.gz`）。

在存储目录下运行：

**Linux Shell：**

```bash
# 扫描目录下的 .whl, .tar.gz, .zip 并按正则截取包名
find /path/to/packages -type f \( -name "*.whl" -o -name "*.tar.gz" -o -name "*.zip" \) -exec basename {} \; \
| sed -E 's/-[0-9].*//' \
| sort -u > packages.txt

```

**Python 脚本（解析标准 Wheel / Sdist 文件名，避免误切带连字符的包名）：**

```python
from pathlib import Path
from packaging.utils import parse_wheel_filename, parse_sdist_filename

PACKAGE_DIR = Path("/path/to/packages")

package_names = set()

for file in PACKAGE_DIR.rglob("*"):
    if file.suffix == ".whl":
        try:
            name, _, _, _ = parse_wheel_filename(file.name)
            package_names.add(name)
        except Exception:
            pass
    elif file.name.endswith((".tar.gz", ".zip")):
        try:
            name, _ = parse_sdist_filename(file.name)
            package_names.add(name)
        except Exception:
            pass

with open("packages.txt", "w", encoding="utf-8") as f:
    for name in sorted(package_names):
        f.write(f"{name}\n")

print(f"解析完成，共发现 {len(package_names)} 个独立包。")

```

### 方法三：导出包含版本号的完整依赖清单（requirements.txt 格式）

如果导出的目的不仅仅是包名，而是为了**连同版本号一起完整备份或迁移**到另一个内网源：

使用 Python 的 `pip-tools` 或在服务器上提取所有文件对应的明确版本：

```bash
# 在包目录中提取完整的 包名==版本号
find /path/to/packages -type f -name "*.whl" -exec basename {} \; \
| awk -F'-' '{print $1"=="$(NF-3)}' \
| sort -u > requirements_all.txt


find /data/03_services_data/http_root/pypi -type f -name "*.whl" -exec basename {} \; \
| awk -F'-' '{print $1"=="$(NF-3)}' \
| sort -u > requirements_all.txt
```
