A. 清掉旧 town ~/gt（你手动执行）

 ```bash
   export PATH="$HOME/.local/bin:$PATH"

   # 1) 停旧 town 的服务
   cd ~/gt
   gt down || true

   # 2) 杀掉旧 town 的 tmux 会话（socket 名 gt-f082e6）
   tmux -L gt-f082e6 kill-server 2>/dev/null || true

   # 3) 确认没有残留进程（重点看 config 指向 /home/vire/gt 的）
   pgrep -af "gt daemon run"
   pgrep -af "dolt sql-server"
 ```

 如果上面还列出指向 /home/vire/gt 的进程，按 PID 杀掉：

 ```bash
   # 示例（PID 以你实际输出为准）
   kill 507896 508125 2>/dev/null || true
 ```

 确认干净后删除目录：

 ```bash
   rm -rf ~/gt
   ls -d ~/gt 2>/dev/null || echo "旧 town 已删除"
 ```
 
 
 B. 把新 town gt_ai 切到 pi（你手动执行）

 ```bash
   export PATH="$HOME/.local/bin:$PATH"
   cd /home/vire/work_luli/gt_work/gt_ai

   # 1) 默认运行时：claude → pi
   gt config default-agent pi
   gt config default-agent        # 复查，应输出：Default agent: pi

   # 2) 同步 pi 的 hooks（生成 .pi/extensions/gastown-hooks.js；这是 agent 能收 mail/nudge 的前提）
   gt hooks sync
   find . -maxdepth 3 -name "gastown-hooks.js" 2>/dev/null | head

   # 3) 授权 pi 信任该 town 根目录（否则每个角色会话都会卡在 “Trust project folder?”）
python3 - <<'EOF'
import json, pathlib
p = pathlib.Path.home() / ".pi/agent/trust.json"
d = json.loads(p.read_text()) if p.exists() else {}
d["/home/vire/work_luli/gt_work/gt_ai"] = True
p.write_text(json.dumps(d, indent=2, ensure_ascii=False) + "\n")
print(p.read_text())
EOF

   # 4) 可选：claude 模板残留目录，不用 claude 可以删掉（保持 doctor 干净）
   rm -rf .claude
 ```

  C. 重启并验证（你手动执行）

 ```bash
   export PATH="$HOME/.local/bin:$PATH"
   cd /home/vire/work_luli/gt_work/gt_ai

   gt down && gt up
   gt status
 ```

 期望输出：

 ```text
   ✓ Dolt: started (port 3308)
   ✓ Daemon: PID xxxxxx
   ✓ Deacon: hq-deacon
   ✓ Mayor: hq-mayor

 ```
